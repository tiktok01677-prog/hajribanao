Help & How to Use

Get started with HajriBanao on your phone or computer.

1. Create your employee list

Choose Employees → Add employee. Enter their name, role, optional phone number, monthly salary, joining date and active status.

2. Record daily attendance

Open Attendance, choose a date and tap Present, Absent or Paid Leave next to the employee. Tap Clear to remove a mistaken mark. The Mark all unmarked as Present option does not overwrite existing marks.

3. Understand the salary calculation

Set Working days per month in Settings (default: 26). Salary earned is monthly salary × min(Present + Paid Leave days, working days) ÷ working days. Absent or unmarked days do not add earned pay. This is an estimate for recordkeeping; configure the rule to suit your business.

4. Record advances and salary payments

Open Salary & Advances → Record advance / salary payment. Select the employee, type, date, salary month to deduct from, and amount. Advances and payments are deducted from that selected month's earned salary.

5. View reports and print a slip

Use Reports to compare attendance, then export a salary CSV. Use the print icon on Salary & Advances to open a print-ready salary slip. Browser printing is supported when your browser provides it. Android WebView printing may need additional native Java implementation.

6. Backup / restore

Settings → Download JSON backup. Store this file safely. To restore, choose Restore JSON backup. Restoring replaces all current data, so make a backup first. CSV exports are for reporting; JSON is for restoring.

7. WebView and downloads

For the Android wrapper, enable JavaScript and DOM storage and load the HTTPS GitHub Pages URL. WebView may need extra native download handling for browser-generated CSV/JSON files and native print integration for slips.
